# English Resources

Catalog of public English courses, tests, sites, and grammar for a static GitHub Pages site.

## Requirements

- A modern browser
- No runtime, build tools, or package installation

## Setup

1. Clone the repository.
2. No dependencies to install.

## Usage

Open `index.html` in a browser. GitHub Pages will serve the site from the repository root.

Pages: Home, Video Courses, Podcasts, Grammar & Reference, Courses & Tests; video series That's English, Vaughan Basic, Vaughan Definitive, Rumbo al inglés, Follow Me Beginner, Gomaespuminglish; podcast series Tu Inglés, Alema, Gramática Popular, Relatos en inglés; alphabet, verb tenses, and the grammar index.

Planned Pages URL: [luismiguelbp.github.io/english-resources](https://luismiguelbp.github.io/english-resources)

## Verification

- Open `index.html` in a browser. No test, lint, or build command applies.

## Project layout

- `index.html` — Home
- `search.html` — Search (filters `search.json` with `assets/js/search.js`)
- `video/` — Video Courses hub and lesson series
- `audio/` — Podcasts hub and lesson series
- `text/` — Grammar & Reference: alphabet, verb tenses, grammar index
- `resources/` — Courses & Tests from external sites
- `assets/css/style.css` — Custom styles
- `AGENTS.md` — agent instructions
- `DESIGN.md` — site UI and link rules
- `LICENSE` — Unlicense
